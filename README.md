# RTX Infrastructure

A modern, responsive website for RTX Infrastructure - a premier architectural and interior design company based in Mumbai, India. This website showcases our portfolio, services, and expertise in creating exceptional living and commercial spaces.

## Features

- **Responsive Design**: Optimized for all devices including 1080p resolution
- **Modern UI/UX**: Built with React, TypeScript, and Tailwind CSS
- **Interactive Components**: Smooth animations and transitions
- **Portfolio Showcase**: Detailed project galleries and case studies
- **Service Information**: Comprehensive service offerings and pricing
- **Contact Forms**: Easy communication and project consultation booking
- **Referral Program**: Client referral system with rewards

## Technology Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom design system
- **UI Components**: Shadcn/ui component library
- **Animations**: Framer Motion for smooth interactions
- **Routing**: React Router for navigation
- **Build Tool**: Vite for fast development and building

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd rtx-infrastructure
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Project Structure

```
src/
├── components/          # Reusable UI components

│   ├── sections/       # Page sections and content
```
